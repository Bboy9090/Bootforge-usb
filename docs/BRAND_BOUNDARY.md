# BootForge Brand Boundary

## Status

**BootForge is an internal engine/library identity, not a public product/store name.**

The public product surfaces are:
- **Boot It Back** for computer recovery and repair workflows.
- **Phoenix Key** for guarded boot/recovery-media creation.

## Reason

An unrelated product named BootForge is already shipping in the same bootable-USB category. Using BootForge publicly would create avoidable marketplace and search confusion.

## Internal use that remains valid

The following may retain BootForge naming:
- `libbootforge`
- internal crates/modules
- internal service contracts
- source directories
- test names
- compatibility APIs
- historical evidence

Do not perform a destructive internal rename solely for branding.

## Visual role

BootForge has no standalone store icon requirement.

When represented in architecture diagrams, use a compact engine/core glyph beneath Boot It Back or Phoenix Key rather than a consumer-facing logo.

## Compatibility rule

Public-brand cleanup must not rename crate identifiers, APIs, source paths, test fixtures, or evidence contracts unless a separately tested migration is required for technical reasons.
